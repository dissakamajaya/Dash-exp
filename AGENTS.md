# Agent Context - House of Exp Dashboard

## Project Overview

This is a landing page / dashboard for the House of Exp ecosystem. It serves as a central navigation hub where users can authenticate and choose which application to access.

## Core Requirements

### User Flow
1. User selects their identity (Aldi, Dissa, or Bil)
2. User enters their password
3. User selects which app they want to navigate to
4. System redirects to the selected application

### Applications in Ecosystem
- **studio.houseofexp.com** - Studio application
- **finance.houseofexp.com** - Finance management
- **rental.houseofexp.com** - Rental management
- **academy.houseofexp.com** - Academy/learning platform
- **houseofexp.com/edit/** - Content editing interface
- **client.houseofexp.com** - Client portal

### Users
- Aldi
- Dissa
- Bil

## Design Considerations

- Simple, clean interface focused on quick navigation
- Secure password authentication
- Mobile-friendly responsive design
- Fast load times
- Clear visual hierarchy for app selection
