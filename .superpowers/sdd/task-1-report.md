## Review fix addendum — 2026-07-16

All six P2 review findings were fixed:

1. `src/App.tsx` resolves `authLoading`/blocked auth states before any hash-route splash and requires a server `session` for `routeApp` rendering.
2. `worker/index.ts` runs the local-mode/localhost gate before login/logout method/body handling.
3. `worker/access.ts` returns typed `503 access_jwks_unavailable` for JWKS timeout/non-200/malformed/network failures while keeping invalid JWT claim/signature failures at `401 invalid_access_assertion`.
4. `worker/local-auth.ts` validates verifier schema, strict base64url salt/hash decoding, iteration bounds, 16-byte salt, and 32-byte PBKDF2 hash during config parse; malformed config is `503 invalid_local_verifiers`.
5. `src/App.tsx` only enables local login for localhost `local_session_required` or `invalid_local_login`, not arbitrary Access `401` errors.
6. `src/App.tsx` plays the Cuelume cue before blocking authenticated user-shape reassignment.
